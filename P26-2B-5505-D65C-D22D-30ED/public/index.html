Bloco de Notas em Markdown com Tags

Crie um ambiente de anotações acadêmicas no qual o usuário escreve em sintaxe Markdown básica em um painel à esquerda e visualiza a renderização HTML simultaneamente à direita. O interpretador de expressões regulares para converter cabeçalhos, listas, negrito e blocos de código deve ser escrito em JavaScript vanilla. Mediante login pelo Discord, o estudante pode salvar suas notas no Cloudflare D1, atribuindo múltiplas etiquetas (tags) a cada documento. O sistema deve oferecer uma barra de pesquisa rápida e filtragem por tags que consulta os endpoints serverless na Cloudflare, permitindo organizar, editar e excluir anotações persistidas na nuvem.
